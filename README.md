One prompt in, a whole neon snake game out. My AI agent took a single sentence, built a playable neon snake game from it in one self-contained HTML file, filmed the build and the gameplay, and the short video went up on X. The game is `game.html`: arrow keys steer, glowing orbs make the snake grow, walls and your own tail end the run, and the score stays on screen. Play code: `makefun-tealeaf-rudder-equator`.

## Run it

Open `game.html` in any browser and press an arrow key to start. To check the entry program the way the grader does:

    mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts

`out/POST.json` is then byte for byte this repository's `POST.json`, naming the X post that carries the video.
